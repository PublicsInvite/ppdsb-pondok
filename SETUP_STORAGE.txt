================

STEP 1: BUKA SUPABASE DASHBOARD
================================
1. Buka browser (Chrome/Firefox/Safari)
2. Copy-paste link ini ke address bar:

=====================================
TROUBLESHOOTING:
=====================================

ERROR: "Bucket not found"
→ Solusi:
  - Pastikan nama bucket PERSIS: pendaftar-files (huruf kecil semua, pakai dash)
  - Refresh halaman Supabase
  - Tunggu 1-2 menit setelah create bucket
  - Clear cache browser (Ctrl+Shift+Delete)

ERROR: "signature verification failed"
→ Solusi:
  - Pastikan checkbox "Public bucket" TERCENTANG saat buat bucket
  - Pastikan Policy INSERT sudah dibuat dengan target role "public"
  - Cek apakah service_role key di environment variable benar

ERROR: "Policy check violation"
→ Solusi:
  - Pastikan semua 3 policies sudah dibuat
  - Policy INSERT dan SELECT harus untuk role "public"
  - USING expression harus "true" (huruf kecil)

ERROR: File tidak bisa diakses/download
→ Solusi:
  - Pastikan checkbox "Public bucket" TERCENTANG
  - Pastikan Policy SELECT sudah dibuat
  - URL file harus dari getPublicUrl(), bukan signed URL

MASIH ERROR?
→ Langkah terakhir:
  1. Hapus bucket "pendaftar-files"
  2. Ulangi dari STEP 3 dengan teliti
  3. Pastikan SETIAP checkbox sesuai instruksi
  4. Jangan skip policy manapun
